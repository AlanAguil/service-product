Desarrolla una aplicación web tipo CRUD usando las tecnologías que prefieras. Puedes usar HTML, CSS, JavaScript, React, Angular, Vue, Node.js, Spring Boot, Django, Laravel, Firebase, MySQL, PostgreSQL, MongoDB, LocalStorage o cualquier otra tecnología que conozcas.

Tu aplicación debe gestionar una entidad de tu elección, por ejemplo: productos, tareas, estudiantes, clientes, libros, cursos, empleados o cualquier otra entidad similar.

La aplicación debe permitir:
Registrar nuevos elementos.
Consultar una lista de elementos.
Editar elementos existentes.
Eliminar elementos.
Cada registro debe tener al menos 4 campos.

El proyecto debe subirse a GitHub y contener un archivo README.md con:
Nombre del proyecto.
Descripción.
Tecnologías utilizadas.
Funcionalidades.
Instrucciones para ejecutar el proyecto.
Evidencias o capturas de pantalla.
Indicación de si se usó IA y para qué.
Se permite el uso de inteligencia artificial, documentación y recursos externos. Sin embargo, cada estudiante deberá poder explicar el funcionamiento general de su proyecto.
